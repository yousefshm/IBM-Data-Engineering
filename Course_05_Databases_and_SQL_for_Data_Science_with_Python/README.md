# Databases and SQL for Data Science with Python

This module focuses on using **SQL as a practical tool** for data exploration, analysis, and interaction with relational databases, with a strong emphasis on real-world querying patterns.

Unlike purely theoretical database courses, the goal here is to **query data effectively**, understand query logic, and integrate SQL with Python for analytical workflows.

---

## 🧠 Key Concepts Covered

- Relational database review (tables, keys, relationships)
- SQL query structure and execution order
- Core SQL clauses:
  - SELECT
  - WHERE
  - ORDER BY
  - LIMIT
- Filtering and conditional logic
- Aggregation and grouping:
  - COUNT, SUM, AVG, MIN, MAX
  - GROUP BY
  - HAVING

---

## 🔗 Working with Multiple Tables

A major focus of this course is understanding how data is distributed across tables and how to combine it using:

- INNER JOIN
- LEFT / RIGHT JOIN
- Join conditions and relationships
- Avoiding common join mistakes (cartesian products, duplicate rows)

This builds the foundation for querying **normalized relational schemas**.

---

## 🐍 SQL with Python Integration

The course introduces how SQL is commonly used alongside Python, including:

- Connecting to databases from Python
- Executing SQL queries programmatically
- Fetching query results into data structures
- Using SQL as part of a broader data processing pipeline

This reflects how SQL is used in **real data engineering and analytics environments**, not in isolation.

---

## 🛠 Practical Skills Developed

Through hands-on exercises, the following skills are reinforced:

- Writing readable and maintainable SQL queries
- Debugging SQL syntax and logic errors
- Understanding query results and edge cases
- Translating business questions into SQL queries

---

## 🎯 Learning Outcomes

By the end of this module, the learner should be able to:

- Confidently query relational databases using SQL
- Join multiple tables to extract meaningful insights
- Use aggregation to summarize and analyze data
- Integrate SQL queries into Python-based workflows
- Prepare data for downstream analytics and reporting

---

## 🔗 Role in the Data Engineering Workflow

SQL plays a central role in data engineering as:

- A primary language for data extraction
- A transformation tool within ETL / ELT pipelines
- A bridge between raw data storage and analytics layers

Mastering SQL is essential before progressing to:
- Data warehousing
- Advanced ETL pipelines
- Big data processing frameworks
