# Introduction to Relational Databases (RDBMS)

This module introduces the fundamentals of **Relational Database Management Systems (RDBMS)** and their role in structured data storage and transactional systems.

The focus is on understanding how data is **modeled, stored, and queried** using relational principles, rather than memorizing SQL syntax alone.

---

## 🧠 Key Concepts Covered

- What is a **relational database**
- Tables, rows, columns, and schemas
- Primary keys and foreign keys
- Relationships:
  - One-to-One
  - One-to-Many
  - Many-to-Many
- Constraints:
  - Primary Key
  - Foreign Key
  - Unique
  - Not Null
- Referential integrity and data consistency

---

## 🗂 Data Modeling Fundamentals

This course emphasizes **logical data modeling**, including:

- Entity identification
- Attribute definition
- Relationship mapping
- Normalization concepts (high-level overview)

The goal is to design schemas that are:
- Consistent
- Scalable
- Easy to query and maintain

---

## 🛠 RDBMS Systems & SQL Overview

At a foundational level, the following are introduced:

- Common RDBMS platforms (e.g., PostgreSQL, MySQL, Db2)
- SQL as a declarative query language
- Basic SQL operations:
  - SELECT
  - INSERT
  - UPDATE
  - DELETE
- Filtering, sorting, and basic joins

The emphasis is on **how SQL interacts with relational structures**, not advanced query optimization.

---

## 🎯 Learning Outcomes

By completing this module, the learner should be able to:

- Explain how relational databases store structured data
- Design basic relational schemas using keys and constraints
- Understand the importance of normalization and integrity rules
- Write simple SQL queries to retrieve and manipulate data
- Recognize when relational databases are the appropriate choice

---

## 🔗 Role in the Data Engineering Lifecycle

Relational databases are commonly used as:

- Source systems for ETL pipelines
- Operational databases (OLTP)
- Intermediate storage layers before data warehousing

A solid understanding of RDBMS concepts is essential before moving to:
- Advanced SQL
- Data warehousing
- ETL and pipeline orchestration
