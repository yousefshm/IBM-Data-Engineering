# IBM Data Engineering Prpfissional Certificate

This repository showcases my hands-on work and learning journey in Data Engineering, aligned with the IBM Data Engineering Professional Certificate.

It contains practical implementations of core data engineering concepts, including data ingestion, transformation, and storage using Python, SQL, and modern data systems.

Through real-world inspired labs and projects, this repository covers:
- Building ETL pipelines using Python and Linux/UNIX shell scripting
- Working with relational databases (RDBMS) and advanced SQL queries
- Designing and querying Data Warehouses
- Handling NoSQL databases and unstructured data
- Processing large-scale data using Big Data technologies and Apache Spark
- Applying foundational data engineering practices and best principles

This repository is designed as a practical portfolio to demonstrate my readiness for entry-level Data Engineering roles, focusing on clean code, reproducible pipelines, and real use cases rather than theory alone.

This repository currently contains a structured PDF summary of the IBM Data Engineering curriculum, focusing on core concepts, terminology, and architectural foundations.

The summary is designed as a concise reference covering key data engineering topics such as Python, SQL, ETL, Data Warehousing, Big Data, and Spark.

Hands-on projects and practical implementations are planned and will be added incrementally as part of my ongoing data engineering practice, turning this repository into a complete applied portfolio over time.
