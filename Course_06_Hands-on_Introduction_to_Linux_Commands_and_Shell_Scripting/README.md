# Linux and Shell Scripting

This module introduces **Linux fundamentals and shell scripting** as essential tools for working with data systems, servers, and automated pipelines.

Rather than focusing on theory, the course emphasizes **hands-on command-line usage** and practical scripting patterns commonly used in data engineering and DevOps environments.

---

## 🧠 Core Topics Covered

- Introduction to Linux operating systems
- Command-line navigation and file system structure
- Essential shell commands:
  - ls, cd, pwd
  - cp, mv, rm
  - cat, less, head, tail
- File permissions and ownership
- Environment variables

---

## 🖥 Working with the Shell

The course builds confidence in interacting directly with systems via the terminal:

- Command chaining and redirection (`|`, `>`, `>>`)
- Searching and filtering text using:
  - grep
  - sort
  - uniq
  - wc
- Understanding standard input, output, and error streams

These concepts are foundational for handling logs, datasets, and automation scripts.

---

## 📜 Shell Scripting Fundamentals

A key component of this course is learning how to automate tasks using shell scripts:

- Writing basic shell scripts
- Using variables and parameters
- Conditional logic (`if`, `else`)
- Loops (`for`, `while`)
- Script execution and permissions

Shell scripting enables repeatable, reliable workflows instead of manual command execution.

---

## 🛠 Practical Skills Developed

By completing this module, the learner gains the ability to:

- Navigate Linux systems efficiently
- Manipulate files and directories programmatically
- Automate repetitive tasks using shell scripts
- Process text-based data from the command line
- Understand scripts commonly used in data pipelines

---

## 🎯 Learning Outcomes

After this course, the learner can:

- Confidently work within a Linux terminal environment
- Write and execute basic shell scripts
- Use command-line tools to preprocess data
- Support ETL pipelines and system-level automation
- Read and understand existing shell scripts in production systems

---

## 🔗 Importance for Data Engineering

Linux and shell scripting are critical for:

- Managing data infrastructure
- Running scheduled jobs (cron, batch processing)
- Automating ETL tasks
- Working with cloud and on-prem servers

Most data platforms ultimately run on Linux — this course ensures you can **operate comfortably at that level**.
